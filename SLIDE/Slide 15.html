14 / THÁCH THỨC & GIẢI PHÁP
Năm bài toán — năm giải pháp thực chiến
🔥 PROBLEM #1 VS Code Simple Browser
Trình duyệt không hỗ trợ cookie · session bị mất
💡 Giải pháp: Session qua URL query string (?sid=...) — fallback tự động khi cookie disabled.
🔥 PROBLEM #2 Performance
Hiệu năng chậm khi nhiều query đồng thời
💡 Giải pháp: Connection pooling (5-100 conn) + Database indexing → giảm 70% query time.
🔥 PROBLEM #3 UI / UX
Giao diện ASP.NET mặc định thiếu hiện đại
💡 Giải pháp: Redesign theo phong cách Instagram · gradient · rounded corners · system typography.
🔥 PROBLEM #4 Encoding
CSV không đọc được tiếng Việt trong Excel
💡 Giải pháp: Prepend UTF-8 BOM (0xEF 0xBB 0xBF) — Excel auto-detect encoding.
🔥 PROBLEM #5 Validation
Validation phía client không đủ — user có thể bypass bằng DevTools
💡 Giải pháp: Double validation — client (UX, realtime) + server (security, bắt buộc) với ModelState attributes & custom validators.
