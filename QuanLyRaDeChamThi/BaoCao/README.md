```powershell
       14_CHUONG9_KIEMTHU.md `
       15_KETLUAN_TAILIEU.md `

       --number-sections
```

👉 **Chi tiết:** Xem file `HUONGDAN_CHUYEN_DOI_WORD.md`

### 4. Chuyển sang PDF

```powershell
# Từ Markdown
pandoc *.md -o BAO_CAO.pdf --toc --number-sections

# Hoặc từ Word (sau khi đã có .docx)
# Mở trong Word → File → Save As → PDF
```

### 5. In ra giấy

```
1. Chuyển sang Word (.docx)
2. Chỉnh format (font, margin, header/footer)
3. In với cấu hình:
   - Paper: A4
   - Margin: Top/Bottom 2cm, Left 3cm, Right 2cm
   - Print: Double-sided (2 mặt)
```
